# Open Scholar Theme

This is the lean host theme for the Open Scholar plugin family. It supplies branding, mobile-first administration, design tokens, plugin integration contracts, Jetpack UI restraint and SEO/social fallback. It deliberately renders no public header or footer.

Data Manager, AI tools, app fields, forms, builders and blocks are external Open Scholar plugins. They are not loaded or packaged by this theme.

See the repository `README.md`, `docs/OPEN-SCHOLAR-THEME-STANDARD.md`, and `docs/ARCHITECTURE.md`.
