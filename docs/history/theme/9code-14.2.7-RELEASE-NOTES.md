# 9Code Theme 14.2.7 — Mobile Editor Focus Update

- Adds a Theme-menu bridge for Core-owned mobile editor presentation controls.
- Appearance → 9Code Display can enable/disable full-screen Edit Panels and default hiding of third-party meta boxes on mobile/tablet.
- Theme does not own meta boxes or plugin data; Core provides the editor presentation layer.
- Public Theme runtime and Conference compatibility remain unchanged.
