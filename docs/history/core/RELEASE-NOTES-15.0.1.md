# 9Core 15.0.1 - Native Editor Space Recovery

- Retires the 9CODE full-screen Post Content/meta-box focus layer.
- Restores all available Post Content and metadata/meta boxes to native WordPress flow.
- Upgrade migration forces focus/hide options OFF even if 15.0.0 previously enabled them.
- Keeps one Editor Tools hamburger for 9CODE/WordPress settings and nonessential Gutenberg toolbar/plugin actions.
- Adds the hamburger to Classic Editor as a small floating control.
- Removes stale focus/backdrop/full-screen classes and nodes if an older cached script left them behind.
- Theme Quick Actions continue to yield on post-edit screens so only one 9CODE editor control remains.
