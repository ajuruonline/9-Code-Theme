# 9Core 14.1.0 — Suite Consolidation & API 14 Operation

9Core 14 is the shared infrastructure/control plane for the 9Code 14 Block Suite.

## Consolidated gains
- durable settings and Theme/Core contract discipline;
- unified AI/Data Manager and ACF/meta/taxonomy/CSV/XLSX round-trip infrastructure;
- Doctor, diagnostics, backup/recovery and frontend editing infrastructure;
- Popular Site + Skin configuration authority consumed by Theme;
- Theme-owned Header/Footer configuration bridge;
- dashboard identity and admin-workspace hardening inherited from 13.5;
- plugin installation remains available through Theme Quick Actions rather than a duplicate Core launcher.

## 14.1 ownership changes
- Core API is now **14**.
- Core no longer loads the old five-button admin quick controls.
- Theme owns visible site chrome and Quick Actions.
- 9 Mason owns block catalogue/allocation/runtime APIs.
- 9Page will consume the suite contract when development is complete.
