# 9 Data Manager 9.10.5 — Lazy Front-End Managers

- When 9Code Theme Quick Actions is active, Post Editor and Category Manager no longer enqueue or render hidden front-end workspaces on every page.
- Theme launcher links open their management screens on demand.
- Data Manager keeps its own floating Post/Category launchers only as a Theme-absent fallback.
- Form Manager, Category Responses and Data Backup behavior from 9.10.4 are preserved.
