# 9 Data Manager 9.10.3 — Edition 9.10

## Product consolidation

9 Data Manager is now the editorial/data workspace in the three-component suite: Theme + Core + Data Manager. Mason and 9Page are discontinued from the suite.

## Admin order

Opening 9 Data Manager opens Post Editor. The visible submenu order is Post Editor, Category Manager, Post Creator, Form Manager, Data Backup.

## Form Manager

Adds persistent form definitions and responses, Create Form, Manage Forms, Responses, shortcode rendering, CSV response download, required-field validation, nonces, honeypot protection and short duplicate-submit protection.

## Data Backup

Adds scoped download/restore for categories, taxonomy terms, pages and post types using Excel, CSV, 9Data Template JSON and full 9Data Pack archives. Structured formats reuse Data Engine preview/conflict/version/rollback controls; full 9Data Packs reuse the mature native post/content recovery engine and may include media.

## Compatibility

Legacy internal module names, PHP classes, option keys and routes are retained where necessary so existing installations and saved data continue to work.
