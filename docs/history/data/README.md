# 9 Data Manager — Edition 9.10

**Current version: 9.10.12**

9 Data Manager is the editorial and structured-data control plane for the synchronized suite:

**9Code Theme + 9Core + 9 Data Manager**

WordPress Pages remain native. Flyer/CPT plugins can use Data Manager forms and data through generic WordPress hooks without a mandatory Page-layer plugin.

Managed surfaces remain Post Editor, Category Manager, Post Creator, Form Manager and Data Backup. Managed forms remain selectable on editable Posts, Pages and show-ui CPTs, with Category Responses and CSV downloads.
