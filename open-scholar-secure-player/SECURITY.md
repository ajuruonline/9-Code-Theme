# Security and deterrence boundaries

Secure Scholar encrypts stored content and validates signed access rules before decrypting. Decrypted video or document pixels must exist during authorised viewing. The system therefore provides layered access control and deterrence, not an unbreakable claim.

Implemented controls include encryption, integrity checks, password-file possession, optional PIN, expiry, opening credits, viewing time, optional installation binding, local clock rollback checks, tamper-checked local usage state, custom viewer controls, watermarks, anti-copy/print/drag actions, static-web interaction curtain and Windows capture exclusion where supported.

The product cannot guarantee prevention of external cameras, kernel/administrator-level tools, modified application code, memory inspection, operating-system compromise or deletion/reset of all local browser history. Global opening counts, immediate revocation and server-authoritative time require an optional online authority in a future release.

The interaction curtain is for first-party/static web learning content. It must not obscure mandatory controls of YouTube or another third-party platform.
