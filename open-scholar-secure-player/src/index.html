Owner backup

Protection controls

Secure Scholar blocks copying, printing, ordinary downloads, right-click, drag, viewer sharing and direct source controls. It adds recipient watermarks, expiry, opening credits, time limits, optional installation locking and tamper-checked local history.

The Windows application also requests operating-system capture exclusion. No software can stop an external camera or every administrator-level capture method.

Supported content

Online: MP4, WebM, PDF, PNG, JPEG and self-contained HTML up to 100 MB. Save Word and PowerPoint as PDF. Windows: the same secure formats, larger-file allowance and direct Office-to-PDF preparation when LibreOffice is installed.

Quick guide

To secure something

  1. Choose your file.
  2. Choose how long, how many openings and viewing time.
  3. Press Secure file.
  4. Download or share the file and password.

To view something

  1. Import the secure file.
  2. Import its password file.
  3. Press Open file.
  4. View your remaining credits.
