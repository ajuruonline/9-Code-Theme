    Settings and privacy

    Everything here is optional. Most people never need to open it.

    What stays on this device

    Files you open are read on this device and never uploaded. Your reading places and recent list are kept only in this browser.

    Device code

    Only needed when a publisher asks you for it, so a protected file opens on this device alone.

    Backup for publishers

    For people who protect files. Save a backup before clearing browser data, so you can still open and protect your files later. The backup is locked with a password you choose.

    Protection explained

    Protected files block copying, printing, ordinary downloads and right-click. They add a watermark, expiry, a limited number of openings and optional device locking.

    No software can stop every camera or screen recording. Protection makes casual copying harder; it is not perfect.

    Supported files

    Open here: PDF, MP4, WebM, PNG, JPG and saved web pages (.html). Protect: the same types, up to 100 MB. Word and PowerPoint: save them as PDF first.

    How to use this app

    Read or watch a file

    1. Press Open a file.
    2. Pick a PDF, video or picture.
    3. Use Previous, Next and Enlarge to read, or Play to watch.
    4. Your place is saved for next time.

    Open a protected file

    1. Press Open a protected file.
    2. Import the .scholar file, then the .scholarpass file.
    3. Enter the PIN if one was sent, then press Open file.

    Protect a file

    1. Press Protect a file and choose it.
    2. Answer the three questions: how long, how many openings, minutes each time.
    3. Press Protect file, then send both files.

    Each setting has a short explanation under it. Open “Advanced settings” only when you need one of the extra options.
