# Secure Scholar Plugin v1 - installation

1. In WordPress, open **Plugins > Add New > Upload Plugin**.
2. Upload `Secure_Scholar_Plugin_v1.0.0.zip`, activate it, and open **Secure Scholar** in the dashboard.
3. Add a Dashboard or menu item named **Secure Scholar** pointing to `/secure-scholar/`.
4. Keep the existing Open Scholar phone shortcut. Do not install a second phone app.
5. The public route opens files. The `/secure-scholar/owner/` route requires sign-in and `edit_posts` permission.
6. Exclude the owner route from public caches. Test the current theme, cache plugin and Open Scholar PWA on real phones.

Online source limit: 100 MB. Save Word and PowerPoint as PDF. The Windows edition uses the same `.scholar` and `.scholarpass` files and supports desktop Office preparation.
