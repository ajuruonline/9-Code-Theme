# Open Scholar Theme 20.2.3 — Visual application management

- Kept the canonical Open Scholar green `#14532D` and dark green dashboard hero.
- Introduced an on-device, dependency-free icon library with distinct semantic inline SVGs, instead of repeating generic Dashicons.
- Added application-specific, accessible dark-colour icon foregrounds with matching pale backgrounds and identifier monograms. These colour accents are strictly confined to individual app cards.
- Each visible app retains a functional description and expandable permission-checked submenus.
- Dashboard remains the first direct navigation button in the right-hand launcher and Quick Actions drawer.
- No changes to authentication, content data, plugin registration, theme activation, or licensing.
