# Open Scholar Theme

This is the lean host theme for the Open Scholar plugin family. It supplies branding, mobile-first administration, design tokens, plugin integration contracts, Jetpack UI restraint and SEO/social fallback. It deliberately renders no public header or footer.

Data Manager, AI tools, app fields, forms, builders and blocks are external Open Scholar plugins. They are not loaded or packaged by this theme.

See the repository `README.md`, `docs/OPEN-SCHOLAR-THEME-STANDARD.md`, and `docs/ARCHITECTURE.md`.

## Open Scholar v20.2.5

Dashboard and Top Bar launcher buttons now use distinct icons. The Open Scholar navigation panel fills the screen from 10% down, and automatically expands/scrolls to the current page/subpage. **Export & Import** and **Backup & Restore** are now distinct dashboard applications and WordPress admin screens. See `docs/RELEASE-20.2.5.md`, `docs/DATA-TRANSFER-VS-RECOVERY.md` and `docs/ULTRON-RABBIT-QA-20.2.5.md` for routes, security constraints and staging procedures.
