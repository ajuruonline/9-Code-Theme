# Open Scholar Theme v20.2.6

Release branch for institution-facing Open Scholar theme update (October 25, 2026).

- Dashboard & Menus settings for per-site visibility, icon, names, descriptions, ordering, and submenu display.
- WordPress menu popup triangles removed.
- All bordered/outlined interface elements have square corners. Borderless surfaces may have slight radius.
- Fixed workspace preferences save action when WordPress admin-post.php does not build the admin_menu registry; accepts only a short-lived server-generated app catalogue.
- Green institutional brand retained (#14532D).
- Distinct Export/Import and Backup/Restore workflows preserved from v20.2.5.
- PHP lint, 17 focused PHP assertions, 11 Python/Chromium regression tests, and ZIP integrity validation passed.

Installable complete theme is in open-scholar-theme-20.2.6.zip; see AUDIT.md. This is a standalone release branch to protect the older Nine Code Theme baseline. Test on a staging WordPress instance before deploying to universities.
