Shared infrastructure/control plane for the current 9CodePress Edition 9.10 suite.

== Current suite ==

* 9Code Theme — safe WordPress presentation shell, design tokens and Quick Actions.
* 9Core — shared contracts, settings, diagnostics, recovery and compatibility infrastructure.
* 9 Data Manager — Post Editor, Category Manager, Post Creator, Form Manager and Data Backup.

WordPress Pages remain native. Flyer/CPT plugins own their own templates through the generic compatibility contract. Mason, the legacy 9Page/Page Builder and the experimental functional Page layer are discontinued.
