# 9Core 14.1.7

## Admin chrome simplification
- Removed image logos from 9Core settings-page heroes.
- Removed the image from the optional workspace context strip and set that strip OFF by default.
- Removed image branding from the WordPress admin bar and set custom admin-bar branding OFF by default.
- Restored native Gutenberg/Site Editor close/hub icons instead of replacing them with a product mark.
- Added a one-time upgrade migration that disables the old workspace strip and branded admin-bar node on existing installs.
- Hid the optional command-palette admin-bar node on tablet/mobile widths and constrained long top-bar labels.
