# 9Core 14.1.2 — Optional Companion Isolation & Surface Contract

## Changes
- Adds `ninecodepress_surface_context()` as a generic additive ownership contract for application surfaces.
- A companion may claim only the request it owns and request Theme header/footer/Quick Actions suppression without becoming a Theme/Core dependency.
- Diagnostics schema advances to 4 and exports the resolved `surface_context`.
- 9 Mason and 9Page 9.77 remain optional separately owned companion products.

## Discontinued Nine Page guard
Former Nine Page / 9.55 Page / 9 Code Page 0.3.x/0.4.x/0.5.x releases, audits and automated outputs are historical only. They are not used as current companion baselines.

Real WordPress diagnostics export and app-surface integration remain required.
