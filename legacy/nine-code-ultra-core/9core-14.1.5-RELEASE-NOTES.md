# 9Core 14.1.5 — Edition 9.10 Three-Suite Consolidation

- Current synchronized suite is Theme + Core + Data Manager only.
- Mason and 9Page are not suite components.
- 9 Data Manager is the authoritative owner of Post Editor, Category Manager, Post Creator, Form Manager and Data Backup.
- Core retains its embedded historical data engine strictly as a fallback when 9 Data Manager is absent.
- Core dashboard links and user-facing ownership language now point to the Data Manager/Post Editor workflow.
