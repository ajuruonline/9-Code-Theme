# 9Code Theme 14.1.5 — Edition 9.10

## Suite consolidation

The synchronized suite is now **9Code Theme + 9Core + 9 Data Manager**. Mason and 9Page are discontinued as suite components. Legacy compatibility helpers may remain dormant so old sites fail safely, but they are not advertised, required, packaged, or launched.

## Quick Actions

When 9 Data Manager is active, the Theme-owned side Quick Actions launcher exposes:

1. Post Editor
2. Category Manager
3. Post Creator
4. Form Manager
5. Data Backup

Mason is no longer inserted into the Quick Actions catalogue or defaults.
